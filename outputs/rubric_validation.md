# Track B validation — does the rubric hold up against blind holistic judgment?
_Generated by `06_trackB_fit.ipynb`. n = 200 universities, 900 judgments, 840 unique pairs + 60 swapped repeats._

## Verdict
**Spearman(Track A, Track B) = 0.790** (Kendall τ = 0.598, Pearson R² = 0.555).

CONFIRMS THE DESIGN — correlated but not collapsed.

The rubric is a **usable fast proxy** — it recovers the broad ordering of 1,226 universities at negligible cost. It is **not a substitute for the judgment**: 44% of the Track B target is not reachable by any straight line through the Track A composite, and that residual is what the model in `07` is asked to learn.

## Reliability of the labels
| statistic | value | reading |
|---|---|---|
| self-consistency (60 swapped repeats, held out of the fit) | **86.7%** (95% CI 75.4%–94.1%) | meets the 0.75 threshold set in the plan |
| chance-corrected agreement | 0.733 | 0 = coin flip, 1 = perfect |

## Where Track A succeeds and where it fails
| pair type | n | Track A predicts the judgment | mean Track A gap |
|---|---|---|---|
| close | 340 | 63.2% | 2.4 points |
| random | 500 | 86.0% | 18.5 points |

Overall the Track A composite calls 76.8% of the 840 judgments correctly.

This split is the core finding. On **random** pairs — where the rubric already sees a wide gap — the two methods agree, which is convergent validity: the rubric is not wrong. On **close** pairs the rubric falls toward chance, because a weighted sum of presence flags cannot resolve a site that has fewer features but uses them better. A holistic reading can, and does. Track B therefore carries genuine signal that no arithmetic over the 69 attributes reproduces — which is precisely the circularity the two-track design was built to break.

## Robustness of the fit
Regularisation C = 10.0 chosen by 5-fold CV log-loss over [0.01, 0.03, 0.1, 0.3, 1.0, 3.0, 10.0, 30.0, 100.0, 300.0, 1000.0]. Fitted without an intercept, so position bias cannot hide in the model; refitting with one gives an intercept of -0.0622.

| variant | Spearman vs. primary fit | top-50 overlap |
|---|---|---|
| all 900 comparisons | 0.9979 | 98% |
| confidence-weighted | 0.9980 | 98% |
| C=3.0 (one notch stronger) | 0.9944 | 96% |

The ordering is insensitive to all three choices, so it reflects the judgments rather than the fitting procedure.

## Confounding check — reported, not resolved
Between-region variance is **21.1%** of the Track B target (Kruskal–Wallis H = 43.30, p = 0.0000); the same figure for Track A is 24.9%.

This is a real effect and it is not explained away. Because collector and region are perfectly 1:1 in this dataset, two readings fit the data equally well — regions genuinely differ in institutional web quality, or the six collectors measured differently — and **no analysis of this data can separate them**. What can be said is that the blind judging did not amplify the confound the rubric already carried (21% vs 25%), and that roughly 79% of the target varies within region, which is the part a model can learn that is not geography. The response in `07` is procedural: leave-one-region-out is reported beside standard CV, and if it collapses, the model was learning region — which will be stated as the result rather than worked around.

## Limitations, stated plainly
1. These are **LLM-elicited expert judgments applied to extracted attribute profiles**, not human ratings of live websites, and must be described that way in any write-up.
2. **One rater.** Self-consistency is measured; inter-rater agreement cannot be, because there is no second rater. This is the single largest threat to the labels' validity.
3. Judgments are made from the blind profile cards, so anything the extractor did not capture — visual design, tone, actual link quality — is invisible to Track B as well.
4. No external validation (QS, Webometrics, student survey) was performed, by decision. No claim of agreement with real user perception is available or made.
